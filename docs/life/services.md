# 校内事务：找谁、带什么、怎样留记录

> 通用方法，整理于 2026-10-03；具体校内政策另行核查。

办理事务先找到负责主体。学籍变动、成绩与选课、住宿报修、资助、就业、图书资源并非同一部门，不把辅导员当成所有问题的唯一处理人。

## 定位流程
从学校或学院官网找到对应通知，读发布日期、适用对象和办理渠道。教务处科室职责可帮助定位，但具体办公安排仍查当前入口。不从第三方截图推断电话或窗口。

## 提问前准备
用两三句话说明年级、专业、事项、已完成步骤和具体障碍。携带通知要求的材料；不在公开群发送证件。问清下一步、截止时间、审核主体及结果如何查询。

## 办理后保存
保存提交回执、版本和结果，重要口头结论可以礼貌请求书面确认。提交不等于批准，系统显示处理中也不等于已完成。

## 把一次咨询变成能执行的下一步

“我这个情况怎么办”往往不足以让老师定位问题。先说明正在办理哪件事，再指出流程卡在哪一步。例如，转入后发现一门原专业课程没有出现在新培养方案的学分统计中，可以这样咨询：

> 老师您好，我是〔年级、学院、专业〕的学生，正在核对转入后的课程认定。原课程〔课程名、课程代码、学分〕已取得成绩，新培养方案中的〔课程名、课程代码〕目前仍显示未完成。我已查看〔通知名称与日期〕，但没有找到这两门课程的对应关系。请问应向哪个岗位提交认定申请，需要哪些材料，结果在哪里查询？若本学期选课截止前尚未认定，是否需要先选目标课程？

这段文字是提问示例，不能证明两门课程可替代。将收到的答复与[课程账本](../study/course-ledger.md)一起保存；在正式认定前，把相关要求记为待确认，并向负责选课或认定的岗位核实可执行的备选安排。

住宿报修可以采用同样结构：说明位置、故障现象、发生时间、已尝试的安全检查和报修单编号，询问是否已受理及下一次查询方式。具体房间号、联系方式只提交给正式办理渠道，公开讨论用脱敏描述。出现漏电、冒烟或其他现场危险时，先停止使用并联系现场管理人员，不等待普通工单回复。

## 个人办理记录模板

以下内容放在自己的笔记中，不作为公开投稿材料。需要上传附件时，按正式通知提供，不因为模板有某一项就额外提交敏感信息。

```text
事项：
适用年级 / 专业 / 校区：
官方通知标题、网址、发布日期：
负责部门与官方办理入口：
截止时间（区分材料提交、补正、结果确认）：

当前状态：待咨询 / 待提交 / 已提交 / 待补正 / 待审核 / 已完成
最近一次联系日期、渠道：
咨询的具体问题：
收到的答复与仍待确认的问题：
材料文件名、版本与提交日期：
回执或工单编号：

下一步动作：
由谁处理：
何时查询或跟进：
截止前的备选安排：
完成依据（结果页面、正式通知或确认文件）：
```

收到补正要求后，保留原提交版本和新版本，注明修改内容；不要用新文件覆盖所有旧文件后失去提交记录。把“下一次查询”写进日历，日期根据官方办理说明或实际答复设定，避免自行承诺一个学校未公布的处理时限。

## 临近截止时间仍未解决

先核对截止时间属于提交还是审核完成，并检查是否有补交、延期或其他正式安排。通过原办理渠道附上回执编号和时间线，直接问“在当前状态下，截止前我还需要做哪一步”。若需转交其他部门，问清接收岗位和材料是否需要重新提交。

系统不可用时，保存错误提示、发生时间与工单信息，向官方渠道报告并询问替代提交方式。截图只能证明当时出现的现象，不能自行视为延期批准。不要反复提交多份互相矛盾的申请；必须重交时，注明与旧申请的关系。

## 没解决怎么办
先确认是否材料不全、问错部门或超出该窗口权限。按正式反馈或申诉渠道描述事实和证据，不公开工作人员私人信息。提交纠错时注明日期，帮助后来者判断是否仍适用。

## 怎样把办理经历分享给后来者

一篇有用的经验记录至少包括：办理年份、适用学院或专业、事项、查到的官方依据、材料类别、真实流程和最终结果。涉及时间时，区分通知规定的期限与自己这一次实际等待的时间。删去证件、账号、工单号和私人联系方式；公开他人的答复前先确认是否适合公开，能概括的内容不直接贴聊天截图。

其他同学可复用的是定位流程和准备材料的方法。个别老师对某一案例的答复、一次特殊批准或某一届的窗口安排，都不能直接推广成全校政策。投稿时可使用[投稿模板](../contribute/templates.md)，把仍未解决的问题留给后续核查。
