# 图书馆、信息检索与数字工具

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

[图书馆](https://lib.cdut.edu.cn/)提供资源与服务入口。借阅、开放时间和校外访问会调整，使用前查看当前说明，不沿用旧帖子中的账号规则。

检索先确定问题和关键词，区分教材、综述、原始论文与官方文档。摘要不等于全文，需要资料时使用合法服务，不共享账号或大量抓取数据库。

## 从一个具体问题开始搜索

“找人工智能资料”范围太大，可以改成“这次分类实验为何训练集表现好、测试集表现差”。先写自己要回答的问题，再列核心概念、同义词与常见英文表达。第一次结果太多时增加对象或约束，太少时减少限定词；记录搜索词和筛选理由，不只收藏结果页。

基础概念先用课程指定教材或其他有明确出处的解释建立框架；想了解一个研究方向时，综述能帮助认识问题和方法分类，但具体结论仍回到原始工作；实现工具时查对应版本的官方文档。不同类型的资料回答不同问题，不把一段工具教程当成研究效果的证据。

沿一篇资料的引用往前寻找基础工作，也可查询后来如何讨论或改进它。引用数量和搜索排序有助于发现资料，不能单独证明结论适用于自己的任务。

## 阅读前先确认资料身份

核对标题、作者、发表或发布位置、时间与版本。相似标题的论文、预印本和后续正式版本可能有差异；文档也可能针对旧软件版本。下载后保留出处与访问日期，避免文件重命名后无法找到原文。

只看到摘要时，笔记标为“摘要阅读”，不要记录成已经核对方法与实验。全文暂时不可获得时，可从合法开放版本或图书馆当前服务查找；仍未获得就保留待核实项，不让 AI 补写自己没有读到的细节。

## 一张阅读记录卡

记录重点是自己的理解和证据位置，不是把全文复制进笔记。

```text
要回答的问题：
资料标题、作者、年份、版本与来源：
阅读范围：摘要 / 部分章节 / 全文
资料主要解决什么问题：
方法、假设与适用条件：
关键结论及所在页码、章节或图表：
数据、评价方式与比较对象：
已理解的内容：
不理解或尚未核实的内容：
与当前课程 / 项目的关系：
下一步（重做例题、查基础概念、阅读引用或做小实验）：
```

阅读完成后，尝试不用原文解释一个关键概念，或用小例子检查方法的适用条件。发现自己只能复述结论、不能解释假设时，回到对应基础；阅读速度和收藏数量不能代替理解。

## 在作业与项目中怎样引用

区分原作者的结论、自己的解释与自己复现的结果。直接引用和改写都按课程或投稿要求注明来源；中文翻译不使原有观点变成自己的成果。记录原文位置，写作时再核对，不仅引用别人转述的参考文献。

复用代码或数据时另查许可与使用要求，引用论文不自动获得代码、数据或图片的再发布权。复现没有成功时，说明环境、修改和验证范围，不把原论文的结果写成自己的实验结果。团队文档中的资料来源由参与者共同核对，避免合并时丢失出处。

为课程、政策、申请和项目分别保存文件。政策记录标题、发布日期、适用范围和查看时间；论文记录方法、证据与不理解的点。重要作业保留多个备份并验证能打开。

可以用“用途—主题—年份”的简单目录保存文件，并为重要修改保留版本与变更说明。定期实际打开一份备份，确认并非只有空目录或损坏文件。准备公开笔记时，检查文件正文、附件、截图和链接中是否包含私人信息，不把自己的私有资料目录整体上传。

学籍材料、成绩单和证件放在私有空间。AI 可辅助解释、草拟和调试，但输出需要核对；涉及隐私、未公开研究或课程要求时，先确认能否上传。

AI 给出论文题目、引用或链接时，逐项回到可访问的原始来源检查是否存在、是否支持所述结论。可以让它帮助列检索词或解释自己提供的段落，但最终阅读记录仍注明实际读到的范围。政策与经验材料的判断方法另见[信息可信度检查](information-literacy.md)，研究记录可参考[科研与合作](../study/research.md)。
