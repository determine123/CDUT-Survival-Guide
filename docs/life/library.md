# 图书馆、信息检索与数字工具

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

[图书馆](https://lib.cdut.edu.cn/)提供资源与服务入口。借阅、开放时间和校外访问会调整，使用前查看当前说明，不沿用旧帖子中的账号规则。

检索先确定问题和关键词，区分教材、综述、原始论文与官方文档。摘要不等于全文，需要资料时使用合法服务，不共享账号或大量抓取数据库。

为课程、政策、申请和项目分别保存文件。政策记录标题、发布日期、适用范围和查看时间；论文记录方法、证据与不理解的点。重要作业保留多个备份并验证能打开。

学籍材料、成绩单和证件放在私有空间。AI 可辅助解释、草拟和调试，但输出需要核对；涉及隐私、未公开研究或课程要求时，先确认能否上传。
