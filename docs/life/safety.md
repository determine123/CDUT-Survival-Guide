# 预算、资助与求助

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

每月记录刚性支出、弹性支出和应急储备。奖助、贷款和勤工助学的资格、金额与节点查学校当年通知，本册不自行设数值。

兼职核实合同主体、工作内容、报酬与结算，警惕先交押金或借用身份开账户。重要决定先找可信赖的人和学校相关部门咨询。

校园账号用独立密码，不透露验证码。有人以老师或招聘方身份要求转账时，经已知官方渠道再次确认。公开截图遮挡证件号、学号、精确住址与二维码。

身体不适或遇险及时联系现场工作人员与当地紧急服务。需要情绪支持，可查看[心理健康中心](https://xljk.cdut.edu.cn/)的当前服务；本册不提供诊断或替代专业帮助。
