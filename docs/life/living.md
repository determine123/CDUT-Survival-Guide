# 住宿、通勤、社团与日常生活

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

本册不列未经核实的宿舍价格、门禁时间与店铺排名。生活投稿注明校区、时间与适用条件。

搬入时检查设施，按正式渠道报修。和室友讨论作息、清洁、噪声与共用品，问题无法解决时记录事实并请辅导员或管理人员协助，避免人身评价。

按课表实测通勤，把雨天和换乘计入余量。寻找实习看实际单程时间和到岗天数，不只看地图距离。

社团先参加一次公开活动，再决定长期加入；确认费用、任务与退出方式。留出自主学习与休息，消费水平和社交频率不代表大学生活质量。

持续失衡时先降低负荷并寻求支持，校内服务从官方渠道核对。
