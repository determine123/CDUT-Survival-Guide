# 新生入学与第一个月

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

先按录取材料和当年通知核对学校、校区、学院、专业与报到地点，再安排交通与住宿。成都理工大学与成都理工大学工程技术学院的制度、生活服务不能混用。

## 出发前
- 按报到通知准备证件和材料，保存纸质与电子副本；不要公开证件照片。
- 先带近期必需品，床铺规格和宿舍规定确认后再买大件。
- 缴费核对收款主体和官方入口，不通过陌生群链接付款。

## 第一周
确认校园账号、教务系统、课程表、校园卡和学院通知渠道。认识辅导员和教学事务老师，保存适用的培养方案。去一次图书馆，实际走一遍住处到教学楼的路线。

## 第一个月
检查课程能否跟上、活动是否影响睡眠、每周是否有自主学习时间。先调整主要问题，不因为别人进了实验室就贸然承诺长期任务。把重要手续记入日历，完成后保存回执。
