# 新生入学与第一个月

> 整理：2026-11-13。通用建议、个人经历与政策分开阅读；当年官方文件优先。

先按录取材料和当年通知核对学校、校区、学院、专业与报到地点，再安排交通与住宿。成都理工大学与成都理工大学工程技术学院的制度、生活服务不能混用。

## 出发前
- 按报到通知准备证件和材料，保存纸质与电子副本；不要公开证件照片。
- 先带近期必需品，床铺规格和宿舍规定确认后再买大件。
- 缴费核对收款主体和官方入口，不通过陌生群链接付款。

## 第一周
确认校园账号、教务系统、课程表、校园卡和学院通知渠道。认识辅导员和教学事务老师，保存适用的培养方案。去一次图书馆，实际走一遍住处到教学楼的路线。

## 第一个月
检查课程能否跟上、活动是否影响睡眠、每周是否有自主学习时间。先调整主要问题，不因为别人进了实验室就贸然承诺长期任务。把重要手续记入日历，完成后保存回执。


## 把待办分成三类，避免所有事情一起赶

第一次到校时，先处理影响当天住宿、身份核验和后续课程的事项，再安排可稍后完成的采购与活动。以下是个人整理方法，不是学校报到手续清单；每项是否需要、在哪里办和何时截止，都应从自己的正式通知确认。

| 类别 | 自己需要查清的问题 | 完成证据 |
| --- | --- | --- |
| 到校与住宿 | 报到地点、受理时间、宿舍入住与必要材料是否明确？ | 正式通知、个人办理结果 |
| 账号与学习 | 账号是否可用，课程表、培养方案和通知在哪里查看？ | 实际登录和本人适用文件 |
| 后续安排 | 哪些事务有截止时间，哪些物品可以确认后再买？ | 日历提醒、待确认问题列表 |

把“已经问过”和“已经办妥”分开：群里有人回复不等于系统已登记；自己填完表也未必等于审核通过。办理结果暂时不明确时，记录当前状态及负责渠道，按通知要求跟进。可参考[校内事务办理方法](../life/services.md)。

## 第一周做一次从课表到教室的核对

逐项确认课程名称、教学班、教学周、时间、地点和信息来源。遇到群消息与系统信息冲突，保存具体冲突并向相应负责人员核对，不自行决定哪一份一定有效。提前走一遍上课路线，并为陌生校区和楼宇留出找路时间。

下载本人适用的培养方案，初步建立[课程账本](../study/course-ledger.md)。系统中能够选到某门课程，不代表它必然满足自己的毕业类别；涉及认定的问题先记录，向学院核实。了解每门课的任务与提交渠道时，可使用[课程任务表](../study/courses.md)。

## 给自己留一份账号与资料恢复办法

检查校园账号的找回方式和自己能够使用的验证渠道，妥善保存必要的恢复信息。不要把密码、验证码或恢复码发给声称帮忙激活账号的人；遇到登录故障，从已确认的学校入口寻找支持渠道。

为通知、课程文件和办理回执建立简单目录。保存一份能在主设备临时无法使用时取回的重要资料，并实际检查是否能够打开。证件和账号信息放在私人空间，公开求助截图前遮盖身份、验证码和二维码等内容。资料检索与备份方法见[图书馆与资料管理](../life/library.md)。

## 第一个月结束时做一次小复盘

用十几分钟回答以下问题，并只选少量可执行的调整：

- 最近一次作业或实验，是否清楚要求、按渠道提交并查看了反馈？
- 哪门课最需要补先修知识？能否写出一个具体卡点去提问？
- 通勤、社团或其他承诺是否挤占了必须课程与正常休息？
- 是否还存在未完成的手续、未确认的费用或错过的通知？下一步由谁确认？
- 当自己遇到学习或生活困难时，知道可以向哪些可信任的人或学校渠道求助吗？

不要把第一个月是否进入实验室、加入多少组织作为适应成功的唯一判断。先建立能持续运行的学习和生活安排，再逐步增加任务。对暂时不确定的方向保留探索空间，不必在刚入学时承诺整个本科阶段的路径。
