# 参考样本：阅读原文，不混作成理案例

这些项目用于理解手册组织与经验写作，不是成都理工大学的政策或录取数据。当前保留链接而不转载文章全文，未来收录转载须先核查许可与作者授权。

- [上海交通大学生存手册](https://github.com/SurviveSJTU/SurviveSJTUManual)：参考学习、研究、工作与个人分享的组织。
- [上海交通大学飞跃手册](https://github.com/SurviveSJTU/SJTU-Application)：参考不同出路、匿名化与投稿背景说明。
- [南方科技大学飞跃手册 2019-Fall](https://github.com/SUSTech-Application/2019-Fall)：历史申请案例，只用于理解写法与过程，不据此判断当前政策。
- [成理工程生存指南 & 飞跃手册](https://github.com/cdutetc-tieba/CDUTETC-Guide)：面向成都理工大学工程技术学院，校内制度与本项目不能互换。

## 阅读时提取什么
背景、年份、目标、关键选择、个人行动、限制、最终状态和复盘。不要仅提取成绩与结果，更不要复制学校名称后将案例归到成理。

成理投稿逐步充实时会减少首页入口，但致谢与来源记录继续保留。任何真正转载的材料需保留作者、来源、许可和原适用范围。
