# 转专业：申请前到转入后

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

转专业可能改变培养方案、课程认定和毕业时间，不能只比较专业名称。本页不公布未经核实的名额、门槛或必过技巧。

## 申请前
1. 找到当年学校通知和目标学院细则，确认适用年级、窗口与限制。
2. 看核心课程、大纲和真实学生项目，判断自己为何想转。
3. 比较已修课程与目标方案，列出认定、补修、先修及时间冲突。
4. 向原学院和目标学院分别确认手续与结果，保存回执。

材料与面试用真实学习和项目解释动机，不贬低原专业。转入后确认学籍、班级、通知渠道、适用方案与正式认定结果。先解决年度开课和先修课，再安排竞赛或实习。

作者转专业时降了一年级，说明转入后的时间成本值得提前核对；该经历不代表所有年级都会降级。[教务处科室职责](https://aao.cdut.edu.cn/jgsz/kssz.htm)可辅助定位学籍事务。
