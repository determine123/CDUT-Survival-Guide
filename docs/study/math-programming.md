# 数学与编程：怎样把基础学扎实

> 通用方法，整理于 2026-10-03；具体校内政策另行核查。

不要把基础课理解为“考过即可”。数学、力学、电子信息和人工智能方向都需要把抽象表达转成可以检查的推理或程序。

## 一周学习循环
课前读定义与例子；课后不看答案重做一道代表题；隔几天做一道变式题。遇到错误先标注是定义不清、适用条件遗漏、计算失误还是表达不完整。错题只抄解答没有用，应记录自己为什么会这样想。

线性代数可以用代码检查矩阵运算与维度；概率统计先说明样本、假设和不确定性；力学题先画图、说明坐标与约束，再列方程。验证数值或量纲，避免只凭最终答案判断。

## 编程入门
先会写函数、处理文件、使用数据结构、读错误信息和编写最小复现。每个程序用正常输入、边界输入和错误输入检查。熟悉命令行与 Git 后，记录一次修改解决了什么问题。

## 卡住时怎样求助
提供题目来源、已尝试的步骤、具体不理解的位置。代码给最小示例、环境、预期和实际输出，不贴私有数据或整张模糊照片。问完后自己重做一遍，确认不是仅听懂了答案。
