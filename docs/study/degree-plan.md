# 培养方案、学分与毕业要求

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

培养方案以本人年级、校区和专业适用版本为准。转专业或分流后，先确认适用方案与课程认定，再排课。

## 课程账本
记录课程代码、名称、学分、类别、先修要求、开课学期、成绩和认定状态。总学分够了，不代表各类别和实践要求都已满足。课程名称相似不代表可以替代。

年度开课课程与先修课可能成为毕业时间的关键路径。每学期结束保存成绩单，检查漏修、成绩未录入和认定申请。毕业、学位、实践与毕业设计分别核对，不仅看系统上的学分总数。

询问学院时带上课程代码和具体冲突，重要结论保留正式通知或书面答复。可以从[教务处](https://aao.cdut.edu.cn/)定位通知，但不把往届同学课程表当成本人培养方案。
