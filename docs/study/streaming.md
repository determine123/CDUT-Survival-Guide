# 电子信息大类分流与方向选择

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

大类录取、转专业与大类分流是不同环节。分流依据、名额、志愿和调剂以本人年级正式文件为准，作者进入人工智能不能保证后来者同样结果。

## 从任务理解方向
比较核心课程、真实项目、日常工作与研究任务。可以试做数据处理程序、基础电路实验或公开数据分析；记录难点、时间和兴趣是否持续，不只看专业名字。

## 填报前核对
- 哪些成绩或综合指标参与排序？
- 志愿数量、时间窗口、调剂与结果确认流程是什么？
- 分流后适用哪个方案，是否要补修，能否按原计划毕业？

上述问题须由当年通知回答。本册不设固定数值。[机电工程学院](https://mee.cdut.edu.cn/)可作为相关信息入口，其他校区和学院分别核对。
