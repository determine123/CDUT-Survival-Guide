# 选课、绩点与考试复盘

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

选课先看毕业所需和先修关系，再看兴趣与时间。朋友说容易的课程未必能计入你的培养方案。

开学阅读大纲，确认考核组成、作业、实验和考试安排。绩点、重修和成绩处理以适用规则为准；本册不凭空给出统一换算公式。

每周把不会的题目归类：概念、计算、表达还是时间问题。数学和编程等后续依赖的基础应持续练习。考前根据大纲与合法练习材料备考，考后记录错因。

讨论与共同提交的边界以课程要求为准。实验保存真实数据，使用 AI 或现成代码须能解释并符合规则。不购买代考、代写或泄露试题。出现成绩疑问时按当年渠道与期限办理，不猜测截止日期。
