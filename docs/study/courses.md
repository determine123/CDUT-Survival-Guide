# 选课、绩点与考试复盘

> 整理：2026-10-03。通用建议、个人经历与政策分开阅读；当年官方文件优先。

选课先看毕业所需和先修关系，再看兴趣与时间。朋友说容易的课程未必能计入你的培养方案。

开学阅读大纲，确认考核组成、作业、实验和考试安排。绩点、重修和成绩处理以适用规则为准；本册不凭空给出统一换算公式。

## 开学先建立一张课程任务表

每门课程至少记录大纲版本、考核项目、提交渠道、截止时间和反馈查询方式。分组实验还要写清个人职责与合并提交的负责人。考核比例尚未公布时记为待确认，不按往年经验直接计算。

```text
课程名称与代码：
大纲 / 课程通知来源及日期：
考核项目与已确认的要求：
任务：
截止时间与提交渠道：
是否独立完成 / 允许怎样合作：
个人职责（团队任务）：
提交文件版本、日期与回执：
反馈结果与需要修改的内容：
下一步：
```

把截止时间放入日历，并留出检查文件、上传及查询提交状态的时间。文件存在电脑里不等于已提交，系统上传成功也未必等于内容完整；提交后按课程要求核对文件是否可打开、附件是否齐全以及是否存在补交提示。老师另行调整安排时，同时更新任务表和日历，保留通知出处。

## 学不会时先区分问题

如果课堂能听懂、独立做题却没有思路，选一道代表题，先不看解答写出已知条件、目标和可用定义，标出第一处无法继续的位置。如果计算经常出错，把推理与计算步骤分开检查，记录单位、符号或边界条件。编程题则先做[最小复现](math-programming.md)，不要把所有功能同时修改后失去问题来源。

连续几次作业出现同一类困难时，带着具体例子向任课老师或助教提问：说明课程、题目来源、已尝试的步骤和卡点，再问应补哪一项先修知识。一次只选择能在近期检验的调整，例如补读对应定义、重做一道基础题或缩小实验范围；之后用新的题目检查是否改善，避免只延长学习时间却重复原来的方法。

若多门课同时落后，先核对最近的硬性截止与先修依赖，分别列出必须交付的最低完整任务和可推迟的额外目标。涉及退选、缓考、补考或重修时，查适用通知并向负责岗位核实条件与时限，不能用“以后再补”代替正式安排。

每周把不会的题目归类：概念、计算、表达还是时间问题。数学和编程等后续依赖的基础应持续练习。考前根据大纲与合法练习材料备考，考后记录错因。

## 怎样做一次有用的考前检查

按大纲列出知识点，用允许使用的练习题检验，而不是只统计读过多少页。对每个知识点检查能否解释定义和适用条件、独立完成一道代表题、判断结果是否合理。对实验或项目考核，核对报告要求、可运行性和个人贡献说明。

练习时可记录用时，但不把某一次模拟成绩当成正式成绩预测。遇到不会的内容，先保留自己的解法再看反馈，复习后换一道题检查。不要把记住某套答案等同于掌握知识，也不要根据未经证实的“必考题”放弃大纲中的其他内容。

## 考后复盘与成绩疑问分开处理

复盘可记录“原来怎样理解、实际卡在哪里、需要补什么、下一次怎样检查”。只记“粗心”通常无法指导调整，可以进一步写成漏读限定条件、符号抄错、没有验证边界或时间分配不合理。

成绩有疑问时，按课程或学校正式渠道核对允许查询的项目，说明自己的具体问题并保存反馈。学习复盘不能替代成绩复核申请；复核也不能保证结果会改变。涉及手续的记录可参考[校内事务办理方法](../life/services.md)，涉及毕业要求的结果则同步更新[课程账本](course-ledger.md)。

讨论与共同提交的边界以课程要求为准。实验保存真实数据，使用 AI 或现成代码须能解释并符合规则。不购买代考、代写或泄露试题。出现成绩疑问时按当年渠道与期限办理，不猜测截止日期。
